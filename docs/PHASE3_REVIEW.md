# 第三阶段审核说明

## 阶段目标

验证“创建复诊计划 → 选择必要病程 → 整理问题 → 设置隐私范围 → 人工确认 → 复制摘要”的完整闭环。摘要只重新排列用户已经确认的资料，不进行医学推断。

## 本阶段交付

- 复诊计划的新建、编辑、列表和删除；
- 首页下一次复诊提示；
- 从当前患者时间线选择必要材料；
- 可编辑和删除的复诊问题模板；
- 默认隐藏患者称呼和出生年份；
- 可选择隐藏医院信息；
- 结构化复诊摘要预览；
- 摘要来源签名和确认快照；
- 资料变化后自动取消确认；
- 确认后的纯文字复制；
- v1/v2 本地数据自动迁移到 v3；
- 完全虚构的示例复诊计划。

## 验收矩阵

| 编号 | 场景 | 预期结果 |
|---|---|---|
| P3-01 | 载入示例病例 | 首页显示下一次复诊，复诊列表有一条虚构计划 |
| P3-02 | 新建计划但不填写目的 | 阻止保存并提示必填项 |
| P3-03 | 选择部分病程材料 | 摘要只出现被选中的记录 |
| P3-04 | 使用问题模板并删除一项 | 摘要中的问题数量和内容同步变化 |
| P3-05 | 首次打开摘要 | 患者称呼和出生年份默认隐藏 |
| P3-06 | 关闭医院显示 | 就诊医院隐藏，病程事件不显示机构信息 |
| P3-07 | 未确认时复制 | 阻止复制并提示先确认摘要 |
| P3-08 | 确认后复制 | 剪贴板获得包含安全声明的文字摘要 |
| P3-09 | 确认后修改计划或材料 | 原确认失效，必须重新确认 |
| P3-10 | 删除被选中的病程事件 | 计划自动移除引用并取消确认 |
| P3-11 | 删除复诊计划 | 原患者档案和病程事件保持不变 |
| P3-12 | 打开第二阶段已有数据 | 档案、病程和报告保留，新增空复诊计划列表 |

## 建议审核路径

1. 在“设置”中重新载入示例病例。
2. 回到首页，点击“准备复诊”。
3. 打开示例复诊计划，检查默认脱敏效果。
4. 进入“调整材料”，改变所选事件。
5. 进入“修改问题”，删除模板并新增一个问题。
6. 回到摘要，关闭医院显示。
7. 确认摘要并复制文字，粘贴到备忘录检查格式。
8. 再修改一次计划，确认旧的“已确认”状态自动消失。
