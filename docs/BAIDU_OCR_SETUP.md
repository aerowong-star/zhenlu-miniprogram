# 百度医疗 OCR 配置

## 架构

小程序不会直接请求百度，也不会接触百度密钥。真实识别链路如下：

```text
报告图片 → 微信云存储临时文件 → recognizeMedicalReport 云函数
        → 百度医疗检验报告单 OCR → 结构化结果 → 人工核对
        → 删除临时云文件 → 本地保存文字结果
```

## 准备工作

1. 在微信开发者工具中为正式小程序开通云开发环境。
2. 在百度智能云文字识别控制台创建应用，并确认已开通“医疗检验报告单识别”。
3. 在微信云函数配置中设置环境变量：
   - `BAIDU_OCR_API_KEY`
   - `BAIDU_OCR_SECRET_KEY`
4. 不要把密钥写入 `project.config.json`、小程序代码、云函数源码或 Git 仓库。
5. 在云数据库创建集合 `ocr_rate_limits`。该集合只保存不可逆用户摘要和每日次数，客户端无需读写权限；建议定期删除过期日期记录。

## 部署云函数

1. 在微信开发者工具中重新导入项目，确认 `cloudfunctions` 被识别为云函数目录。
2. 找到 `recognizeMedicalReport`，安装依赖。
3. 选择“上传并部署：云端安装依赖”。
4. 在云端配置上述两个环境变量，重新部署函数。
5. 使用脱敏测试报告完成一次调用，并在云存储中确认临时文件已删除。

## 接口限制

- 当前接入的是百度 `medical_report_detection` 接口。
- 支持 JPG、JPEG、PNG、BMP。
- 百度要求图片 Base64 编码并 URL 编码后不超过 4 MB；客户端先采用 2.5 MB 原图上限，云函数还会做最终编码大小检查。
- 百度返回患者/报告基本字段以及项目名称、结果、单位、参考区间、结果提示等项目字段。
- 云函数默认限制每位微信用户每天最多调用 10 次，以控制滥用和付费风险。

## 故障排查

- “尚未配置百度 OCR 凭证”：检查云函数环境变量，不要在客户端补密钥。
- “图片编码后超过 4 MB”：裁剪到报告主体或降低图片尺寸。
- `Open api daily request limit reached`：百度测试额度或付费额度已用尽。
- 微信云开发不可用：确认正在使用正式 AppID，且当前项目已关联云开发环境。
